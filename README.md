A typographic briefing of verified 21 November 2026 world news in one 1024×1024 PNG. The program copies a fixed original poster to `/output/entry.png`. Sources and event dates are in `SOURCES.md`.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png`. The image is drawn by `tools/render_infographic.py` and stored at `assets/entry.png`; `main.py` only copies that file, so two runs produce the same bytes.
